# Ejercicio 1 - README

Este archivo describe cómo ejecutar los scripts que resuelven los problemas del tp3

## Requisitos

Se requiere tener instalado Python 3
### En Ubuntu/Debian:
```bash
sudo apt update
sudo apt install python3
```

## Ejecución

Para ejecutar el archivo con la resolución del ejercicio 1, utiliza el siguiente comando en la terminal:

```bash
cd problema1
python3 solucion_ejercicio1.py
```
