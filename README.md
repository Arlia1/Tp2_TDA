# Ejercicio 1 - README

Este archivo describe cómo ejecutar el script `ej1pd.py`.

## Requisitos

Se requiere tener instalado Python 3 en el sistema. Para instalarlo, sigue los pasos según tu sistema operativo:

### En Ubuntu/Debian:
```bash
sudo apt update
sudo apt install python3
```

## Ejecución

Para ejecutar el archivo con la resolución del ejercicio 1 utilizando **programación dinámica**, utiliza el siguiente comando en la terminal:

```bash
cd ejercicio1_PD
python3 ej1pd.py
```
